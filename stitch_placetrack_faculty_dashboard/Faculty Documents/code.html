Private S3 Storage Protocol

In the intended architecture, student documents are stored in private S3 buckets and accessed through temporary signed URLs. Faculty access should be read-only. This front-end prototype does not connect to S3, issue signed URLs, or validate actual uploads. A displayed upload status is not proof of institutional verification.
